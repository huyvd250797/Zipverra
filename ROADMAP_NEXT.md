# Zipverra Pro — UX/UI Roadmap after v3.4.0

**Baseline:** Zipverra Pro v3.4.0 — Mobile Layout & Navigation Redesign (Graphite Navy + Emerald).

## Next: v3.5.0 — Premium Workflow Experience

- One guided Repo → Upload → Review → Confirm → Activity flow with minimal repeated labels and explicit user confirmation.
- A cleaner change summary, secure file selection and clear critical/blocking messages.
- Better active progress stages, network failure guidance, and verified commit/PR outcomes.
- No artificial percentages, auto-push, auto-merge or repeat attempts after ambiguous GitHub mutations.

## v3.6.0 — Modal, Bottom Sheet & Motion Refinement

- Test native iOS Safari/PWA keyboard avoidance, scroll containment, sheet gesture handling and correct focus restoration.
- Tune subtle motion to the device; support Reduce Motion without loss of status information.

## v3.7.0 — Performance & Accessibility Polish

- Measure and optimize LCP / INP / CLS and tab latency on real mobile hardware.
- Review VoiceOver, reachable touch targets, color contrast and PWA lifecycle.

## v3.8.0 — Visual QA & Stable UI Release

- Finish full Next.js/Vercel production build verification, GitHub E2E regression and mobile screenshots.
- Validate ZIP Download Save to Files, Push/PR/Quick Edit/History/Rollback and recovery workflows.

**Deferred:** breaking GitHub backend changes and large-file streaming redesign.
